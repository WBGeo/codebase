# Components

WBGeo is organized around four modeling components, each covering one step in the geoscientific workflow. Select a component below for its full manual.

| Component | Description |
|---|---|
| [Structural Modeling](structural_modeling/Manual_structural_modeling.md) | Reconstruct 3D geological structure from surface points and orientations using implicit interpolation methods. |
| [Meshing](meshing/Manual_meshing.md) | Generate 3D watertight meshes from the structural model for use in numerical simulation. |
| [Process Simulation](simulation/Manual_simulation.md) | Interface with numerical solvers (currently SfePy) using meshes generated in the previous step. |
| [Visualization](visualization/Manual_visualization.md) | Inspect results in 2D and 3D, and connect to immersive XR/VR visualization via LiquidEarth. |
